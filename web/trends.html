统计口径与更新方式

原始散点是去重后的完整响应，以用量上报时间定位。默认可见 TPS = 输出 token（含推理）÷ 完整响应耗时；实际 TPS = 同样的输出 token ÷（响应耗时 − 逐次首 Token 等待）。TTFT 的 + 表示日志估算，实际 TPS 的 ≈ 表示扣除了估算等待，并非精确解码速度。逐次等待不使用轮次级 TTFT 代替。WebSocket 等未记录 HTTP 压缩日志时，≤ 表示首个输出项的等待上界，不参与实际 TPS 汇总。缺少可靠时间的响应不绘点，另列数量。

同一模型按推理档位和服务层分组，多个会话合并，再按固定时间窗口汇总，默认 10 分钟。耗时加权吞吐量 = 窗口内输出 token 总数 ÷ 对应计算耗时总和；可见 TPS 用完整响应耗时，实际 TPS 仅用有逐次等待记录的响应及其扣除等待后的耗时，也等于按响应耗时加权的 TPS，长响应占更大权重；并发会话的耗时分别相加，因此不是按墙钟时间计算的总吞吐量。中位数与等权均值将每次响应作为一个等权样本。

聚合点位于时间窗口中间，大小表示累计响应耗时，悬停可查看样本数、token 和耗时权重；当前尚未结束的窗口会随新响应更新。空窗口不补值，遇到空窗或相邻窗口的实际样本间隔超过窗口长度时断开连线。连线只表示窗口间趋势，不表示期间持续生成。关闭滤波时仅显示原始散点，不直接连线。滤波设置仅保存在本机浏览器。

叠加原始散点后，悬停或键盘聚焦可查看具体响应；服务层为日志请求设置，继承值会注明，不证明服务端实际处理层级。趋势按时间独立读取，不受对话明细“最近 N 轮”限制。后台每 0.5 秒采集最新日志，此页每秒请求更新；暂停显示或隐藏页面会停止本页请求，不停止后台最新日志采集。历史补读未结束时，图中数据尚不完整。

每次先左键点击图框选中，再滚轮缩放或使用视图按钮；同一时间只选中一张图，选中时高亮边框并显示“已选中”。点击图框外或另一张图取消原选择，保留已有比例；未选中时滚轮正常滚动页面。键盘可用 Tab 聚焦图框，Enter 或空格选中，Escape 取消。实时刷新保留选中状态。
