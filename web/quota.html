规则、假设与官方来源

Codex 官方 credits rates 是积分，不是 API 美元价格。订阅内含额度的 Fast / ultra fast 倍率分别为 2.5× / 8×；购买积分分别为 2× / 6×。模型基础积分率以本页加载的官方规则为依据。

默认采用 Codex 标准积分表，每次请求的完整输入上下文均照计，包含重复上下文；缓存输入是总输入的一部分，不将缓存写入再加一次。推理 token 已包含在输出中。目标请求总处理 token = 输入 + 输出。

超过 272,000 输入 token 的输入/缓存 2×、输出 1.5× 仅有 API 规则依据；只有主动选择“API 长上下文情景”才应用，并不表述为 Codex 官方规则。

额度快照按独立 bucket 与 primary / secondary 周期处理；重复快照不相加，重置和分段边界不连线；重置时间的轻微漂移由后端统一判断分段。仅最新连续段参与估计，超过 6 小时的上报空窗断段。单一账号是本页估算假设。本机日志可能遗漏其他设备、客户端或历史消耗，积分与额度更新也可能延迟，因此估计区间不构成额度保证。
